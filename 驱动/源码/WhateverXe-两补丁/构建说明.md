# 自行编译 WhateverXe 0.8.0「两补丁」版

发布包 `驱动/WhateverXe.kext/` 已经是编译好的成品，一般**不需要自己编译**。
只有在升级上游版本、或想核对补丁内容时才需要按本文操作。

## 一、目录内容

| 文件 | 用途 |
|---|---|
| `apply_local_patches_2.py` | 两补丁锚点脚本。每条补丁的锚点要求在源码全文**恰好出现一次**，否则直接报错退出 |
| `构建说明.md` | 本文件 |

补丁逐条说明见 `文档/本地补丁说明.md`。

## 二、准备

1. 从上游官方仓库取 **0.8.0** 源码树：<https://github.com/b00t0x/WhateverXe>
   （用 tag `0.8.0` 的源码包，不要用 DEBUG 产物）。
2. 把源码树解压到本目录并命名为 **`src-2补丁`**（脚本里硬编码了这个目录名），
   使其结构为 `src-2补丁/WhateverXe/kern_xe.cpp`、`src-2补丁/WhateverXe/kern_xe.hpp`、
   `src-2补丁/tools/build.py`。
3. 准备构建依赖（不需要 Xcode，用 `xcrun clang++`）：
   - `MacKernelSDK-master`：<https://github.com/acidanthera/MacKernelSDK>
   - `Lilu.kext`：<https://github.com/acidanthera/Lilu>（本机用 1.7.2 头文件）

## 三、打补丁

```bash
cd 驱动/源码/WhateverXe-两补丁
python3 apply_local_patches_2.py
```

脚本会打印每条锚点是否唯一，然后写入两处补丁：

- **P1-a** `adlsCapturePanelPWM()` 的 FUSE 门禁：去掉 `fuse & 0x01000000` 要求；
- **P1-b** `wrapADLSPanelBacklight()` 的门禁与 16 位亮度夹取；
- **P2** `wrapPlainPanelPower` 的路由（只放行 `hwSetPanelPower(2)`，其余 no-op）；
- **P2-b** 钩子实现；
- **hpp** `orgPlainPanelPower` / `wrapPlainPanelPower` 声明。

> 0.8.0 在 `kern_xe.cpp:13782` 还有**第三处**同样的 bit24 门禁
> （`tglPanelTimingBIOS`，只服务 Display13 面板），本机是死代码，**故意不改**。
> 不要用文本编辑器全局替换 `(fuse&0x01000000)`。

## 四、编译

输出目录必须先删（官方 `build.py` 不会自动清理）：

```bash
rm -rf out-080-2补丁
python3 src-2补丁/tools/build.py \
  --sdk  "$PWD/sdk/MacKernelSDK-master" \
  --lilu "$PWD/Lilu.kext" \
  --output "$PWD/out-080-2补丁" --release
```

产物校验：

```bash
shasum -a 256 out-080-2补丁/WhateverXe.kext/Contents/MacOS/WhateverXe
# 本机 14 版：5dbfbbbff483babcfd5ede660e1140ecc38c1e45af1b8901358d48e7925eb053
```

若哈希不同，先确认上游源码 tag、MacKernelSDK 与 Lilu 版本；不同工具链编译出的二进制允许有差异，
但**必须重新做运行时验证**（`脚本/4-重启后自检.command` + `脚本/5-熄屏唤醒回归.command`），
不能只看编译成功。

## 五、装到 EFI

把编译出的 `WhateverXe.kext` 替换 `EFI/OC/Kexts/WhateverXe.kext`（目标已存在时用 `rsync -a`，
不要用 `cp -R`），并确认 boot-args 里 `-nodisplaysleepDC6` 仍在。
`-nodisplaysleepDC6` 替代了原来的第 3 处补丁，**不要恢复三补丁版**。

## 六、验证判据

- `TGLRecoverySinglePassRequested` / `Ready`、`WhateverXePanelPowerHooked`、
  `TGLMMIOStrongUCRouted`、`TGLAcceleratorAdmissionReady`、`ADLSPanelPWMReady` 全 Yes；
- `TGLWEXDozeDCGuardReady` / `TGLWEXFBStateRouted` **不存在**；
- 亮度能停在中间档（不是 0 / 满亮两档）；
- 连续熄屏 ≥85 秒后唤醒，零 `TrainingError`、状态回 4、面板供电回 `02`。

`Requested=Yes / Ready=No` 表示 donor 逐字节校验没过，立即回退。
