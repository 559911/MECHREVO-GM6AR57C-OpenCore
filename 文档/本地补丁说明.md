# 本地补丁说明（v16 / 2026-11-14 · WhateverXe 0.8.2）

本版 EFI 内 `WhateverXe.kext` 是 **0.8.2 + 2 处本地补丁** 的编译版
（二进制 `1e8937825ec01993394488394626f860b81a9d823b7e2dc6775b4f739c1a5c60`）。
`驱动/WhateverXe.kext/` 是同一份的独立副本。正常情况下只需核对，不需要自己编译。

两处补丁均已对上游 0.8.2 源码逐条复核，**上游仍未修**，且没有官方等效启动参数。

## 一、P1 · ADL-S 内屏背光去掉 FUSE bit24 门禁

- **位置**：`adlsCapturePanelPWM()` / `wrapADLSPanelBacklight()` 一带的
  `fuse & 0x01000000` 判断。
- **本机状况**：`FUSE(0x42000) = 0x8C000000`，bit24 = 0。上游要求该位为 1，
  不打补丁就只有「0 亮度 / 满亮」两档。
- **补丁**：去掉该门禁，并夹取 16 位亮度。实测可停在任意中间档（如 `24182/65403 = 37%`）。

**0.8.2 的第三处同门禁故意不改**：`kern_xe.cpp:13787` 新增的一处
「从 BIOS 捕获面板时序」也检查同一位，只服务 Display13 路径，本机是死代码。
0.8.2 全文件共 3 处 `0x01000000`（约 13787 / 13837 / 13866），
**后两处被补丁改掉，第一处保留**——这是预期状态，不是漏改。

> 升级 WEX 时**不要全局替换** `(fuse & 0x01000000)`，会误改 Display13 路径。

## 二、P2 · 唤醒黑屏的面板供电 no-op

- **原因**：原生 `hwSetPanelPower(0)` 会切断 eDP/AUX 供电，本机第三方面板重训必失败，
  熄屏后唤醒即永久黑屏。
- **补丁**：`wrapPlainPanelPower` 只放行 `hwSetPanelPower(2)`（上电），
  其余状态返回成功且不动硬件。
- **验证**：v14 转正时 8 轮熄屏唤醒回归（正式判据 2 轮连续熄屏 193 / 223 秒），
  零 `TrainingError`、零新增 panic。

## 三、P3 已删除，由 `-nodisplaysleepDC6` 承担

第 3 处补丁（Doze 期间不武装 DC6/DC9）已删除，不用再打。苹果
`AppleIntelFramebufferController::start` 解析 `-nodisplaysleepDC6` 后把 `+0xC29` 置 0，
`setDCState` 在 `0x47336` / `0x4746B` 跳过 `enableHWDC6/SWDC6`；
原生其余流程照跑，比打补丁改动面更小。**不要恢复三补丁版**，那是倒退。

WEX 的 23 个启动参数里**没有**面板供电 / 背光开关，别试图用 WEX 参数替代上面两处补丁。

## 四、运行时判据（必看 IORegistry）

| 键 | 期望 |
|---|---|
| `TGLRecoverySinglePassRequested` / `Ready` | 全 `Yes` |
| `WhateverXePanelPowerHooked` | `Yes` |
| `TGLMMIOStrongUCRouted` | `Yes` |
| `TGLAcceleratorAdmissionReady` | `Yes` |
| `ADLSPanelPWMReady` | `Yes`，且亮度非 0 / 满亮 |
| `TGLWEXDozeDCGuardReady` / `TGLWEXFBStateRouted` | **不应存在**（出现即装错旧三补丁版） |

`Requested=Yes / Ready=No` 表示 donor 校验没过，立即回退。

⚠️ 装 Graphics pkg 前**必须先删掉卷上已有的

「atomically shoved」进去，顶层不再出现 `.bundle`。

## 六、升级 / 重装时注意

- 升级 Graphics 包先用 `pkgutil --expand-full` + `cmp` 比对主文件：
  **`AppleIntelTGLGraphicsFramebuffer` 是补丁偏移的比对基准**，
  它逐字节不变则相关偏移仍有效。
- 换 WEX 版本必须**同步换 `AppleIntelTGLCompat.kext`**（0.8.1，在 `/Library/Extensions`）。
- 换 NVRM 必须按新二进制重新生成绑定表并重编 `SMCNvidiaGPU`
  （本版 2.1 绑 NVRM 3.0，anchor `0x1a1c0`）；出现
  `matches none of the N known builds` 就是驱动换了。
- 自行编译 WEX：`python3 src/tools/build.py --sdk <SDK> --lilu <Lilu.kext> --output <out> --release`。
  `-nopsr` 不是 WEX 参数。

补丁锚点脚本与构建说明见 `驱动/源码/WhateverXe-两补丁/`（v14 时期的基线，
换 WEX 版本时须先按新源码重新核对锚点）。

## 七、传感器读取

```bash
工具/smcread k TG0D F2Ac
```

**必须带 `k` 子命令**：不带子命令只打印内置固定键表，`F2Ac` / `F3Ac` 不在表里，
会误判成没注册。GPU 温度也可看 `ioreg -r -c NVAccel` 的 `Temperature(C)`。
`kern.nvgpupower` 单位是 **mW**；成功终态是 `polling mask 0xff / 500 ms`，不是 `bound NVRM`。
