## 四、核对方法

```bash
cd "GitHub 发布版本"

# 1) 文件数与 config
find EFI -type f | wc -l                       # 209
shasum -a 256 EFI/OC/config.plist              # a8208ca6…
plutil -lint EFI/OC/config.plist               # OK

# 2) 逐文件核对 EFI（清单里是相对 EFI/ 的路径）
python3 - <<'PY'
import hashlib, pathlib
root = pathlib.Path('EFI')
bad = []
for line in pathlib.Path('文档/EFI文件清单-SHA256.txt').read_text().splitlines():
    if not line or line.startswith('#'): continue
    h, rel = line.split('  ', 1)
    p = root / rel
    if not p.exists() or hashlib.sha256(p.read_bytes()).hexdigest() != h:
        bad.append(rel)
print('不一致文件：', bad if bad else '无')
PY

# 3) 两个自制 kext
shasum -a 256 EFI/OC/Kexts/WhateverXe.kext/Contents/MacOS/WhateverXe
shasum -a 256 EFI/OC/Kexts/SMCNvidiaGPU.kext/Contents/MacOS/SMCNvidiaGPU
```

## 五、发布前已执行的完整性检查

- 全包（含二进制文件）扫描自用版 `PlatformInfo > Generic` 的四项真实值
  （序列号 / MLB / SystemUUID / ROM 字节）：**零命中**，发布包内不出现任何一处真实三码。
- 全包无 `.DS_Store`、`._*`、`__MACOSX/`、`.bak`、`config.plist.before-*`、`*.orig`。
- 6 个 `.command` 均 `chmod +x` 且 `bash -n` 通过；脚本内不含本机绝对路径。
- `工具/smcread` 可执行；HiDPI override 的 `flags=9 + 0x00A00000` 条目存在。
- 发布包根目录含 `.gitignore`，排除大压缩包与运行记录。
- 全部生成文件不含任何 AI 水印（显式、隐式）。

## 六、注意

- `1401` 安装器会在登录后自动改写引导介质上的 `config.plist`，届时上表的 config 哈希会变化，
  属正常；改写前它会留 `config.plist.before-1401-<时间>` 备份，改完要重新核对 boot-args（见 README 步骤 4）。
- 使用者填入自己的三码后，`config.plist` 哈希必然变化，此时只需保证**其余 208 个文件**与清单一致。
